# Homebrew Tap (jonathank55)

Offizieller Homebrew-Tap für die macOS-Terminalwerkzeuge von Jonathan ([@jonathank55](https://github.com/jonathank55)).

> [!NOTE]
> Die hier bereitgestellten Programme sind **ausschließlich deutschsprachige Werkzeuge** für macOS.

---

## Enthaltene Pakete

### 1. EasyDateien (`easydateien`)
Minimalistischer, hocheffizienter und rein **deutschsprachiger Terminal-Dateimanager** für macOS mit integrierter interaktiver Konsole und Schnellnavigation.

#### Installation
```bash
brew install jonathank55/tap/easydateien
```

Oder in zwei Schritten:
```bash
brew tap jonathank55/tap
brew install easydateien
```

#### Verwendung
Nach der Installation stehen zwei Befehle zur Verfügung:
```bash
easydateien      # Dateimanager im aktuellen Verzeichnis starten
ed               # Kurzbefehl / Alias
easydateien -v   # Version anzeigen
easydateien -c   # Konfigurationsmenü öffnen
```

---

## Aktualisierung
```bash
brew update
brew upgrade easydateien
```
